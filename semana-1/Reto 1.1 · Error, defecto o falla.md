Tabla: 
1. Es un error porque el analista entendió mal una indicación y pasó antes del código, durante la planeación.
2. Es un defecto porque alguien escribió el código mal y quedó guardado así.
3. Es una falla porque el cliente transfiere S/ 5,000 exactos y la app dice "Límite superado" haciendo que el cliente vea el error y defecto de antes.
4. Es un defecto porque es algo dentro del diseño que ya quedó guardado.
5. Es una falla porque un cliente ya está viendo el defecto que quedó del diseño.
6. Es un error porque es algo que hizo el dev al escribir el código. 


Ejemplo: 
El programador escribe mal una etiqueta del saldo en el código -> Error
La etiqueta mal escrita queda guardada en el código haciendo que el saldo no se actualice -> Defecto 
Un cliente ve un cero en su saldo cuando el debería tener cierta cantidad -> Falla
